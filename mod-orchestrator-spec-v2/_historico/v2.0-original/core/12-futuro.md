# Contratos para futuro

## Downloads

Provider abstrato para download, metadata, autenticação, update check e cache. V1 não implementa.

## Tools

Registro de executáveis externos com argumentos, working directory, environment e associação ao jogo/profile.

## Collections

Manifesto declarativo de mods, versões, regras, load order e opções de installer.

## Save games

Namespace por profile e ações de copy/move/import.

## Extensions

Pacotes instaláveis com manifest, capabilities, versionamento, permissões e ciclo de vida.

## Cloud/backup

Exportação/importação de configuração e estado, nunca como requisito do core.

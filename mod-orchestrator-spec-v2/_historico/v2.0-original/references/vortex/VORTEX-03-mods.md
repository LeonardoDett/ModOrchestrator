# VORTEX-03 — Mods

## Estrutura

Toolbar + filtros + tabela + Get More Mods + Drop Zone + Multi-action + Info Panel.

## Toolbar observada

Install From File; Check for Updates; Categories; Manage Rules; Deploy; Purge; Reset to Manifest; History; Open; Tutorials. Há também opções específicas por jogo/extensão.

## Estados/ícones

Vortex comunica update, endorsement, tracking, dependencies, conflitos resolvidos/não resolvidos e overrides por arquivo.

## Aplicação

**ADOPT:** tabela densa, filtros, multi-action, dropzone, painel lateral e toolbar.

**ADAPT:** Downloads/updates ficam fora da V1, mas contratos devem estar preparados.

# VORTEX-05 — File conflicts

## Fluxo

1. Detectar conflito.
2. Notificar usuário.
3. Abrir diálogo de conflitos.
4. Mostrar mods envolvidos.
5. Mostrar conflito na ordem de mods.
6. Definir vencedor.
7. Criar regra.
8. Permitir exceções por arquivo.
9. Recalcular estado.

## Insight

O Vortex permite escolher arquivos individualmente entre mods conflitantes. Isso evita que a decisão seja apenas "A vence B" para todos os arquivos.

## Aplicação

**ADOPT:** conflito por arquivo + regra persistida + explicação do vencedor.

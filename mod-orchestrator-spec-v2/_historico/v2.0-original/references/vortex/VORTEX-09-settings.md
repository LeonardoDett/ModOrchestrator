# VORTEX-09 — Settings

## Grupos observados em documentação da comunidade sobre a interface atual

Interface; Vortex/Application; Download; Workarounds; Theme.

Exemplos relevantes: profile management, GPU acceleration, automações, notificações, multi-user mode, update channel, privacy, download folder, threads, bandwidth, NXM links, sandbox e theme customization.

## Aplicação

**ADOPT:** separar settings por intenção.

**REJECT:** copiar configurações de download na V1, pois download direto não faz parte do escopo inicial.

Fonte primária da estrutura: https://github.com/Nexus-Mods/Vortex/wiki
Referência complementar independente: https://github.com/modcommunity/how-to-use-vortex-and-basics

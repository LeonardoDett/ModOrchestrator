# Referências de fluxo — Vortex

Esta pasta contém **somente comportamento de referência do Vortex**. Não são requisitos automáticos do produto.

## Como interpretar

- `VORTEX-*` = fato/fluxo observado.
- `ADOPT` = decisão adotada pelo Mod Orchestrator.
- `ADAPT` = comportamento usado como base, mas reorganizado.
- `REJECT` = comportamento deliberadamente não adotado.

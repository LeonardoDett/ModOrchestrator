# VORTEX-11 — Triagem

## Padrão observado

Vortex usa notificações para problemas como conflitos e oferece caminhos para a tela/diálogo responsável pela correção. Há também histórico e logs para investigação.

## Aplicação

**ADOPT:** notification -> diagnostic -> action -> revalidation.

Um toast não substitui um diagnóstico persistente quando o problema continua existindo.

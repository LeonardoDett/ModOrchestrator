# VORTEX-08 — External Changes

## Fluxo

Quando arquivos gerenciados são alterados externamente, Vortex detecta divergência e apresenta diálogo. O usuário pode reverter ou manter/aplicar a alteração.

## Aplicação

**ADOPT:** divergência é entidade de triagem.

**ADAPT:** nosso sistema classifica missing/modified/replaced/moved/unexpected.

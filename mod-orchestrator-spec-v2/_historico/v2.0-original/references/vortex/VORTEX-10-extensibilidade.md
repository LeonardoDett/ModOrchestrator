# VORTEX-10 — Extensibilidade

## Observado

Vortex usa extensions para adicionar suporte de jogos e funcionalidades. A API possui registros para mod types e load order, além de exemplos com installers, ferramentas, save games e pipelines específicos.

## Aplicação

**ADOPT:** adapter/extension como fronteira.

**ADOPT:** capability registration.

**ADAPT:** nosso extension model será desenhado para segurança e versionamento desde o início.

# Changelog

All notable changes to Mod Orchestrator are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses [Semantic Versioning](https://semver.org/).

The section of each version is the text of its GitHub Release and of the "what's new" shown by the in-app updater (D105). Write it for players: what changed for them, not how.

## [1.0.0] - unreleased

First stable release: everything Vortex offers for mods installed from local files, with explicit mod priority, deploy plans and safe recovery. Windows 10 and 11 (x64), English and Brazilian Portuguese.

### Games
- Finds Skyrim Special Edition / Anniversary Edition on Steam, GOG and Epic, and lets you locate any installation manually.
- Generic games defined by you (folders and targets), several instances of the same game, hide, stop managing (with purge) and open folders.

### Mods
- Install from ZIP, 7z, RAR and folders, several at once by drag and drop, through an install queue; archives are kept for reinstalling.
- FOMOD installers with images, conditions and your previous choices on reinstall; SKSE goes to the game root automatically.
- Duplicates and variants, categories, notes, highlight, detected content, mod types, reinstall and remove (with or without the archive).

### Order, rules and conflicts
- Visible mod order with separators; rules ("wins over", "requires", "recommends", "incompatible") move only what is needed and explain why. Cycles are refused when created.
- Every file conflict has a known winner. Review conflicts in their own screen, pick a winner per file or exclude files.

### Deploy
- Hardlink, symlink or copy. See the plan before it runs; every deploy is journaled and verified, and an interrupted one is recovered.
- Original game files are backed up outside the game folder and restored on purge. Nothing the manager does not own is ever deleted.
- Changes made by other tools are detected and reviewed file by file; files generated by tools can be captured into a mod.

### Plugins and load order
- Plugins list with ESM/ESL/light flags, missing or misplaced masters and limits; native sort, rules, groups and locked positions; `plugins.txt` written after deploy and external edits reviewed before anything is overwritten.

### Profiles, diagnostics and recovery
- Profiles: create, clone, compare, transfer selections and restore points.
- One place for problems, with actions that lead to the fix; notifications, history with undo, technical log and a support bundle.
- Play with pre-launch checks; database backups (automatic and manual) and a recovery screen if the database is damaged.

### Installation and updates
- Per-user installer: no administrator rights. Uninstalling keeps your data unless you ask, and never touches mods or game folders.
- Optional update check (off by default, the only network access of the app): downloads are checked against the release checksums and signature before they run.

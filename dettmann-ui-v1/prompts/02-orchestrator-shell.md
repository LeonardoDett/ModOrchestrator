# Cursor Prompt — Mod Orchestrator shell

Read all Dettmann UI skills and `docs/orchestrator-primitives.md`.

Build the desktop shell using the existing library before creating custom components.

Use:

- `Workspace`
- `Sidebar`
- `Navbar` or a composed header
- `ResourcePage`
- `Toolbar`
- `Command`
- `FilterBar`
- `MasterDetail`
- `Inspector`

The shell must visibly preserve 60/30/10: the game workspace should be predominantly canvas/surface, navigation should provide the structural 30%, and brand green should be reserved for important actions/focus/selection.

Do not implement mod business logic in UI components.

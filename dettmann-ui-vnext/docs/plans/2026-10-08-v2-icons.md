# dettmann-ui v2 — Ícones animados e loaders: plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Catálogo próprio de ~63 ícones monolinha com partes animadas (modos `action` e `loop`, intensidade pela ênfase), família `Loader` que substitui `Spinner`, e adoção mínima nos componentes da lib.

**Architecture:** Cada ícone é dado (`defineIcon`: partes JSX + coreografias montadas com um vocabulário central de técnicas). Um runner lê `readMotion` no ícone e executa por parte com `animate()` (gestos) ou a nova `animateLoop()` (estados contínuos). Um controlador delegado por documento dispara o `action` no hover/press/foco do controle interativo mais próximo.

**Tech Stack:** TypeScript 5.7 strict, React ≥18, WAAPI, Tailwind v4, Vitest 4 + jsdom + Testing Library, tsup, Vite (playground).

**Spec:** `dettmann-ui-vnext/docs/specs/2026-10-08-v2-icons-design.md`

## Global Constraints

- Diretório de trabalho: `dettmann-ui-vnext/` (comandos `npm` rodam nele).
- Nenhuma dependência nova. Nenhuma biblioteca de animação.
- Componentes, ícones e loaders não escrevem cor, duração, curva nem keyframes CSS: cor = `currentColor`/papéis L3; tempo/curva/amplitude = `readMotion` (`m.springDuration`, `m.ease`, `m.amp`, `m.stagger`). Exceção prevista na spec: `period` de loop é dado da técnica.
- Geometria copiada do Lucide 0.468 (`node_modules/lucide-react/dist/esm/icons/<nome>.js`, array `__iconNode`), viewBox `0 0 24 24`, `fill="none"`, `stroke="currentColor"`, `stroke-linecap/linejoin="round"`, `overflow="visible"`.
- Mapa `size → strokeWidth` e classes de tamanho idênticos ao `Icon` (`xs 1.5 · sm 2 · md 2 · lg 2 · xl 1.75 · 2xl 1.5`; `h-3 w-3` … `h-10 w-10`).
- `amp` por nível: `calm 0.45 · responsive 1 · expressive 1.6`. Limites com `amp` 1,6: `translate ≤ 3`, `rotate ≤ 30°` (ícones de rotação natural — refresh, undo, settings, sun, moon — até 180°), `|scale − 1| ≤ 0.25`; `spin` e `flip` isentos.
- Loop sob redução de movimento: opacidade `1 → 0.5 → 1`, `2000 ms`, infinito. `action` sob redução: transforms removidos por `animate()`; `draw`/`undraw`/`trail` usam `reduced` = opacidade `1 → 0.4 → 1`.
- Textos embutidos por prop (D-009). `Loader` padrão `label="Loading"`.
- Commits direto no `master`, mensagem em português, terminando com `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Ao fim de cada task: `npm run typecheck` e `npm test -- --run` verdes. jsdom não tem `Element.prototype.animate`: testes que esperam animação fazem stub em **`Element.prototype.animate`** (ícones são SVG, não `HTMLElement`), seguindo o padrão `fakeAnimation` de `src/__tests__/motion.test.tsx`.

## Review Focus

1. **Controle desabilitado** (`<button disabled>`, `aria-disabled="true"` em link/menuitem) com ícone dentro — não deve animar em hover, press nem foco. Teste na Task 4.
2. **Listas grandes** (DataTable/Tree com centenas de ícones) — montar 200 ícones adiciona os listeners do documento uma única vez, e desmontar todos os remove. Teste na Task 4.
3. **Ícone em overlay portado** (item de `Menu`/`ContextMenu` renderizado via `Portal`) — o controlador por documento toca o ícone do `role="menuitem"` portado. Teste na Task 4.
4. **Troca rápida de estado** (`loop` true→false→true, `playKey` mudando várias vezes, desmontar no meio) — nenhuma animação órfã: toda `Animation` anterior recebe `cancel()`. Teste na Task 3.
5. **SSR / sem `document`** (`renderToString`) — ícone e `Loader` renderizam o SVG estático sem exceção e o controlador não é instalado. Teste na Task 3.

Renderização (spec 4.2): `<svg … data-animated-icon={name} data-trigger={trigger}>` → `<g data-part="root" style={fillBox("50% 50%")}>` → um `<g data-part={k} style={fillBox(origin[k] ?? "50% 50%")}>` por parte. Partes citadas por `draw`/`undraw`/`trail` (em `action` ou `loop`) têm seus elementos `path|line|polyline|circle|rect|ellipse` clonados com `pathLength={1}` (recursivo via `Children.map`/`cloneElement`). `fillBox(o)` = `{ transformBox: "fill-box", transformOrigin: o }`. Classes: `cn("shrink-0", ICON_SIZE_CLASS[size], intent && "text-intent-fill", className)`; a11y igual ao `Icon`.

Runner `playChoreography`: `m = readMotion(svg)`; para cada chave, alvo = `[data-part=chave]`; técnicas em array tocam em paralelo; `delay = t.delay + index·m.stagger`. `action`: `animate(el, m.reduced && run.reduced ? run.reduced : run.keyframes, { ...run.options, delay })`. `loop` sem redução: `animateLoop(el, run.keyframes, { period, easing, delay })`; `loop` com `m.reduced`: **um** `animateLoop` no `root` (o próprio `animateLoop` aplica `REDUCED_LOOP`). Retorna as animações não nulas.

Componente: estado interno em refs — `actionAnims`, `loopAnims`. `handle.play()`: se há `action` e não está tocando e `!loop` → `actionAnims = playChoreography(svg, action, "action")`; `isPlaying()` = alguma com `playState === "running"` (fakes sem `playState` contam como tocando até `finished` resolver). `playKey`: efeito que ignora a primeira execução e, nas seguintes, `cancel()` nas atuais e toca. `loop`: efeito que, se `true` e `definition.loop`, cancela `action` e inicia; cleanup cancela; `loop` sem coreografia → `console.warn` em dev (uma vez por nome). `registerIcon(svg, handle)` no efeito de montagem. Validação em dev no `defineIcon` (spec 4.1/12): nome kebab-case, partes referenciadas existem; em produção, definição inválida vira ícone sem `action`/`loop`.

**Interfaces:**

- Produces:
  ```ts

  export function findControl(el: Element): Element | null;   // el.closest(INTERACTIVE_SELECTOR)
  ```

Comportamento (spec 5): listeners `pointerover`, `pointerdown`, `focusin` no `document`, `{ capture: true, passive: true }`. `pointerover`: só `pointerType` `mouse`/`pen` e `relatedTarget` fora do controle. `pointerdown`: `button === 0`. `focusin`: `control.matches(":focus-visible")` (envolver em `try` — jsdom pode não suportar; sem suporte, considerar `false` exceto quando o último evento de teclado precedeu o foco: registrar `keydown` também para essa heurística). Controle desabilitado (`:disabled` ou `aria-disabled="true"`) não toca. Ícones = `control.querySelectorAll('[data-animated-icon][data-trigger="auto"]')` filtrados por `findControl(icon) === control`; para cada, `getIconHandle(icon)?.play()` (o próprio handle ignora se já tocando).
